titbit.mappings.fields_as_keys(key_fields)

Create a dictionary where the keys are derived from specific fields in the items of the iterable.

Parameters:

key_fields (int or tuple of int) – The index or indices of the fields to use as keys.

Returns:

A function that takes an iterable and returns a dictionary.

Return type:

Callable

>>> data = [{'id': 1, 'value': 'A'}, {'id': 2, 'value': 'B'}]
>>> fields_as_keys(['id'])(data)
{1: {'id': 1, 'value': 'A'}, 2: {'id': 2, 'value': 'B'}}

titbit.mappings.iterable_to_dict(iterable, *, key_func=<function identity>, value_func=<function identity>)[source]

Aggregate an iterable into a dict (generate_key_values with egress=dict). By default each item maps to itself; pass key_func and/or value_func to shape the keys and values.

>>> from operator import itemgetter
>>> pairs = [('a', 1), ('b', 2)]
>>> iterable_to_dict(pairs, key_func=itemgetter(0), value_func=itemgetter(1))
{'a': 1, 'b': 2}
titbit.mappings.key_and_value_fields(key_fields, value_fields)

Create a dictionary where the keys and values are derived from separate fields in the items of the iterable.

Parameters:

  • key_fields (int or tuple of int) – The index or indices of the fields to use as keys.

  • value_fields (int or tuple of int) – The index or indices of the fields to use as values.

Returns:

A function that takes an iterable and returns a dictionary.

Return type:

Callable

>>> data = [{'id': 1, 'value': 'A'}, {'id': 2, 'value': 'B'}]
>>> key_and_value_fields(['id'], ['value'])(data)
